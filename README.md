# Lessons Learned 
Credit to:  Chris Johnston cjohnston079 on TOP Discord.  Chris gave invaluable
feedback to my first submission

Make use of HTML text elements, don't just shove everything in div elements.  IE
paragraphs, headings. Be cognizant of screen readers:  the elements are not to
be skipped.  They provide structure that is key to a readable page and code.  
There are more specialized elements, but this is a start.

Use consistent spacing between elements IE apply either bottom or top spacing to 
every element, not top here, bottom there.  Margins add space between elements
but margins can collapse.  Note to self, look more into gap.  Padding adds space
WITHIN elements (IE between contenet of an element and it's border)
